# Meeting Room MVP

Учебный MVP системы бронирования переговорных комнат.

## Архитектура

- `cmd/server` — точка входа HTTP-сервера.
- `internal/booking` — доменная модель и правила бронирования.
- `internal/postgres` — схема и SQL-запросы PostgreSQL.
- `web` — Vue 3 интерфейс без сборки на первом этапе.

## Запуск

1. Запустите PostgreSQL:

```powershell
docker compose up -d
```

2. Установите строку подключения (PowerShell):

```powershell
$env:DATABASE_URL = "postgres://meetings:meetings@localhost:5433/meetings"
```

3. Запустите приложение:

```powershell
go run ./cmd/server
```

Откройте http://localhost:8080.

## Первый вертикальный сценарий

1. Выберите дату.
2. Найдите комнату по вместимости.
3. Создайте встречу.
4. Повторите бронь на пересекающееся время: API вернёт `409 Conflict`.

## План развития

1. Модель и миграция PostgreSQL.
2. API комнат и бронирований.
3. Проверка пересечений на уровне БД.
4. Vue-календарь.
5. Изменение и отмена броней.
6. Авторизация и роли.
7. Отчёты и тесты.
